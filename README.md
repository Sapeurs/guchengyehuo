# 孤城夜火

以南明孤城为背景的原创二维点击探索解谜游戏。现有序章「偏房疑云」与六关正篇，剧情从军械失踪延伸到真假回文、东门换防和城楼闭关。

## 当前可玩内容

| 关卡 | 可往返场景 | 主谜题 |
| --- | --- | --- |

| 第一关 · 军器库夜查 | 3 | 6 |

六个正式关卡另有 18 张独立手绘背景、36 份可回看文书、12 种新实物道具图样。谜题包括实物木闩、残印转正叠合、配重、顺序、文书比对、残片拼合、透光、方向转轮、路线、连杆复位和证据对应。三处场景中的线索与工具互有关联，六关连续通到结局。

- 第一关精修：木闩有碰撞与退回规则；残印需要转正、叠合并找到两处吻合损伤。老军匠有可选话题，开箱与透光会改变场景，并加入巡兵灯影与脚步演出。
- 标题可“重玩第一关精修版”，先备份第一关记录；可在篇章选择中恢复。其他五关与序章进度保留。
- 原有序章与存档保留，序章末可直接进入第一关；标题也可选任一关开始，各关进度分别保存。
- 场景物件没有自动悬停名称、边框或答案高亮；按住 H 或主动点察看才短暂显示位置点。
- 场景、背包、物件近景使用同一实物图样；先选择道具，再在目标上使用。机关内也可取出随身物品。
- 文书、人名与解谜线索简体优先，保留竖写和毛笔质感；可放大阅读。
- 每道主谜题有三层主动提示；错误不扣生命、不销毁道具，局部摆放可重置。
- 自动保存已解机关、道具使用、原始记录、机关摆放和当前场景，刷新后从标题继续。
- B 背包，H 察看，L 手记，Esc 返回。以桌面鼠标和键盘完成验证；窄屏使用响应式布局，尚未做移动设备触屏实机验收。

## 本地运行

Node.js 22 或更高版本。

    npm install
    npm run dev

## 检查与构建

    npm test
    npm run build

`dist` 为静态构建输出。本项目的当前托管入口为根路径；若改为 GitHub Pages 项目子路径，需要统一调整 CSS 中以 `/assets/` 开头的资源地址，不能仅改 Vite base。

## 代码结构

- `src/game.ts`、`src/main.ts`：保留的序章状态与 Phaser 场景、近景交互。
- `src/campaign-data.ts`：六关故事、场景、道具、文书、谜面、提示与依赖。
- `src/campaign-state.ts`：正篇状态、道具使用、谜题判定与存档恢复。
- `src/campaign-ui.ts`、`src/campaign.css`：正篇场景、机关、背包、手记、过场与篇章选择。
- `src/items.ts`、`src/objects.css`、`src/wiping.ts`：序章实物原画与擦拭交互。
- `src/chapter-one.ts`、`src/chapter-one-view.ts`、`src/chapter-one.css`：第一关实物机关、人物话题与演出。
- `src/foley.ts`：本地 Web Audio 拟音与环境风声。
- `src/game.test.ts`、`src/campaign.test.ts`、`src/chapter-one.test.ts`：序章和六关的流程、依赖、答案与恢复验证。
- `docs/six-chapter-campaign.md`：六关范围、内容与验收口径。
- `docs/qa.md`：历次实机验证记录。

## 素材与授权

场景与实物由本项目生成，正式机关图形由可编辑代码绘制。可读文字由真实字形排版，不依赖生成图片里的随机文字。正篇新增原画在 `public/assets/chapters/`；提示词、来源与构图记录见 `docs/art-chapters-*.md` 和 `docs/art-chapter-tools.md`。

字形按用途采用 Ma Shan Zheng、Noto Sans CJK SC、LXGW WenKai TC 等本地子集。授权文本保留于 `public/assets/FONT-LICENSE.txt` 和 `public/assets/fonts/`。新增子集内部字体名称已重命名。详见 `docs/typography.md`。

本作城池、人物、口令与机关均为虚构。玩法取材于点击探索解谜的通用操作组织方式，未使用《纸嫁衣》的剧情、图片、音乐或具体谜题内容。

## 验证

27 项状态、答案、依赖、木闩可逆性和存档测试通过；六关 36 道主谜题已在桌面浏览器实际操作通关，并走到最终名册更正结尾。当前验证没有把自动化已知解通关当作玩家盲测；难度、实际时长和提示使用率仍需玩家反馈。
