# 第一关：发现顺序与推理回报（第18版）

用户目标：顺畅、有“原来如此”的解谜体验。范围为第一关，后五关不在本轮重做。

## 研究依据

本次依据开发者公开访谈、演讲与开发日志分析方法；没有将资料阅读描述为亲自试玩这些商业游戏。

|---|---|---|

## 第一关的思考路径

| 玩家最初知道什么 | 自己做的事 | 新理解 | 下一步问题 |
|---|---|---|---|
| 库吏声称甲三已验讫，陆昭却被拘。 | 打开甲三号箱。 | 交进库的箱中没有军器。 | 簿上究竟收了什么？ |
| 带来的底单和库中原册记着同一批号。 | 在两份原件上圈记录并看。 | 收讫日期早于起解日期，两份记录不能同时照实成立。 | 这批箱还留下什么原始痕迹？ |
| 箱底有破碎的旧签。 | 按字行与连续印框接纸。 | 表面去向与底单相同，但边角有两层纸。 | 覆纸下面是什么？ |
| 薄纸中透出重墨。 | 翻纸、移向灯光、细看。 | “东营”下另有“西渡”，还留着朱印。 | 旧印在哪里见过？ |
| 拘令从开场即随身携带，可以回看。 | 自己拿拘令作参照，叠合并圈两处磨损。 | 原来只代表个人威胁的拘令，与被改签的军器发生联系。 | 谁实际拿过这枚印？ |
| 旧签指向河边，但文书也可能失实。 | 提灯照轮槽、察看擦痕和芦苇。 | 现场痕迹与西渡相互支持。 | 去西渡核货、核经手人。 |

开箱、日期可以先后交换；车辙可在开箱后独立调查。透光需先拼好同一张签；核印需先露出旧纸上的印。没有为凑数量再加排序或结论选择题。

## 实施的关键变化

- 底单从序章随身带来，不再在前院重复拾取；拘令也从进入第一关时可查看。旧存档补足原件，其他章节的进度不重置。
- 清理开场、场景描述、道具描述、调查列表和默认台词里的提前答案。具体位置与完整操作只放在主动求助中。
- 日期圈选后不自动判完；玩家主动并看，错选反馈说明比较对象的问题。正确后留在原件上，收好底单才发生巡兵事件，刷新后保留这段停顿。
- 拼签纸角可直接继续看纸背；灯下露出的旧印可直接带到簿房核看。
- 核印先呈现旧签，参照物由玩家从已有原件中选出。单圈一处不立即告诉玩家这一处对不对。
- 朱印统一为本作虚构的“军务关防”，序章拘令、随身拘令、旧签与叠印使用同一印模；日期仍为序章已定的六月十一日。
- 收紧推断：箱底无压痕不能证明从未装货；提前收讫不能单独证明伏击预谋；同印不能直接证明签发者亲自作案。

## 仍然需要验证

开发者知道解法。功能测试与这次已知解的流程试玩不能代替乐趣验收。

建议至少3位不知道答案的人独立玩第一关，尽量不在旁边讲解。重点在结束后听他们复述：

1. 为什么怀疑交割记录？依据哪两份原件？
2. 为什么想到拿拘令比较？是在自己想到前就被台词告知了吗？
3. 西渡从哪里得来，又用什么互证？
4. 哪一步是在思考，哪一步只是找按钮？
5. 哪一刻出现了意料之外、但回看又合理的理解？

记录卡住的原因；分别处理“没找到入口”“看不清字”“不知道能怎么操作”和“没有想到线索之间的关系”。前3类应优先消除，最后一类不能统一靠直接报答案解决。
