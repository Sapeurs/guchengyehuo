# 物件与探索提示修订

日期：2026-11-11

用户反馈：随身物品使用线框符号，与写实场景原画不一致；鼠标一移到关键位置就出现名称和方框，削弱自行观察的过程。

## 实机与官方资料参考

1. 《纸嫁衣》官方 Steam 页面与画廊：
   https://store.steampowered.com/app/1735950/Paper_Bride/
   观察门扉、文书、室内物件的材质、光照与场景融合。公开静态图不能证明每个平台的完整悬停行为，因此这里不推断它的所有交互规则。
2. Fireproof 官方《The Room 4: Old Sins》：
   https://www.fireproofgames.com/games/theroomoldsins
   官方将物件表面质感、检查细节、发现隐蔽机关作为体验重点。本项目采用“先看物件，再通过操作认识用途”的取舍，不复用其图像、音效或谜题。

## 本版交互规则

| 状态 | 画面反馈 |
| --- | --- |
| 正常鼠标经过场景 | 仅鼠标指针变化；无物件名、方框、光圈 |
| 键盘聚焦 | 淡虚线保留键盘定位能力；朗读名称保留 |
| 按住 H | 暂时显示细小位置点，松开即收回；不显示名称 |
| 点击察看按钮 | 仅短暂显示位置点，1.4 秒后自动收回 |
| 背包未选物品 | 原画缩略物件，无常驻名称和逐格方框 |
| 背包选中物品 | 下方显示名称与查看入口；同一物件缩略图随鼠标拿起 |
| 点击场景或查看近景 | 通过文书、动作和陆昭心声获得具体信息 |

没有自动计时提示，也不随鼠标指向的目标揭示道具是否适用。提示页由玩家主动打开。

## 素材一致性

`src/items.ts` 统一管理物件原画路径。背包、场景拾取物、选中物、获得物提示、蘸水动作、匣内遗物均复用这些路径。腰牌脏净与布条干湿使用成对原画；详细腰牌保留可排版字迹和可擦泥污。

原有工具栏的线条符号只表示菜单、手记、声音等操作。实物道具不再用工具栏图标代替。

未调整谜底、道具前置条件、原有存档键或后续关卡范围。
