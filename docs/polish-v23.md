# 第23版：第一关的核心推理

目标是让空箱成为可验证的疑问：封住箱口是否就能保证军器仍在箱内？本版只重做第一关主线；其余五关保持第22版的关卡内容。

## 游玩结构

- 开箱后，老军匠只承认看过箱口封签，没有替玩家保证箱里有货。
- 撤掉六片拼字。c1-p3保留兼容ID，换为箱底改造试验：上盖横木与底槽短销独立，玩家可以反复松扣、拉回底板、试抬箱盖。
- 单独锁住箱口或单独拉开箱底都不算完成；底板退出时亲手试出上盖仍锁住，才确认“可绕开箱口卸货”。这证明一条可能通路，没有直接认定当时是谁卸货。
- 试验得到旧签；也允许先从衬布下取出旧签。漏拿旧签不会形成死路。
- 旧签直接展开，对光查看覆改，不再用字块拼图限制拿到正文。
- 第一关离开需要开箱、箱底试验、日期核对、旧签去向四条主线。印章和车辙留作可选深查，之后仍可回访；第二至六关完成规则不变。
- 离关对白与结尾按实际查过的可选证据生成，不宣称已查过印模或车辙。
- 主线提示优先指向未完成的核心调查。原件可直接从衣囊摆到手边。

## 画面与保存

箱底关闭、箱底抽出、试验后前院全景使用三个对应新美术。上盖横木单独运动，铁箍遮挡关系保留。拖动有原生范围控件作为键盘替代；范围控件不显示数字密码。发现字幕避让关键开口。

新草稿采用23前缀，检查横木、短销、板位与实际试验结果。旧版未完成拼字草稿局部重置，其他机关和后续关卡保留；旧版已完成记录不清除，可重新游玩第一关体验新试验。发现演出在进度保存后打开，中断后可续接。第一关的重玩与恢复继续使用已有备份。

- TypeScript及生产构建通过。
