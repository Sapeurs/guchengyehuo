# 两份原件直接验印 · v17

用户再次反馈第三处按钮无反应，并质疑甲乙丙选择的设计依据。本轮撤掉整组三选一，不再用编号改名来延续同一套设计。

## 变更

- 只保留拘令留印与箱底旧封签两个有叙事来源的对象。直接摊开、对照，在旧签印上圈出相同的外框缺口与印文裂痕。
- 删除调查入口与通用入口的旧印选择、旋转及其事件处理；原先两套验印渲染收敛为同一个组件，避免回看或其他入口落到旧版甲乙丙界面。
- 标题改为“同印的痕迹”，求助文字和人物反应只描述两份原件，不再引用第三处或乙处。
- 完成后可分开、再次对照原件；已确认的圈记与关卡结果保留。
- 保留旧存档格式。原来真实旧签上的圈记可继续；虚构备选印迹上的圈记清除，其余记录保留。旧方向字段在载入时归正，已解记录保持已解。

## 验证

- 37/37 项测试通过，生产构建通过。新增渲染回归检查：两个原件标签始终存在，调查和回看均没有选择或旋转入口。覆盖旧选片迁移、部分圈记延续、完成记录回看和其他章节保留。
- 预览浏览器从旧4/6记录继续，只有两份原件。使用鼠标坐标实点“分开看原件”，状态可切换。
- 备份后重新调查：开箱、取残签、拼合、提灯透光，然后进入验印；实点对照，圈错、擦去、圈中外框均有对应反馈。
- 一处圈记后刷新仍保留，再实点分开原件、拖动拘令留印到旧封签，确认对照由关闭变为开启，最后实点印文裂痕完成验印。
