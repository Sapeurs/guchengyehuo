## 1. 已确定的方向

- 主角：明军斥候陆昭。
- 主线：押运途中遭伏击，返回孤城后查军械去向、追查内奸，最终阻止清军借伪装援军入城。
- 开场悬念：活着归来的陆昭，在军籍中被登记为阵亡。
- 本章时间范围：子时前的一段夜间调查。时间随剧情节点推进；首章不设真实倒计时。
- 本章进入点：老军匠已经帮助陆昭暂时脱离拘押，将他藏入偏房，并留下从押运队收回的物品。拘押与救助以短对白交代。
- 美术方向：写实手绘、旧木石与纸张质感，冷月光对比暖烛光。物件可辨识，低照度不能妨碍解题。
- 当前三张图是风格概念图。正式场景应拆出可拾取物、可变化部件、机关近景；线索文字由界面排版。

### 2.2 转化为本项目的规则

| 参考方式 | 在本作中的应用 |
|---|---|
| 点场景、进近景、回大场景 | 桌面、床脚木匣、军械账册、封签和印迹分别有独立近景 |
| 收集物品后在指定环境使用 | 用湿布清理腰牌，将封签置于烛光前检查 |
| 多条线索组合而非单处抄答案 | 暗匣次序由两份点验笔记共同限定 |
| 同一物件再次观察得到新信息 | 封签先拼合读到正面，再透光发现覆盖的旧字与官印 |
| 解谜结果推进人物和故事 | 每个主要谜题增加一项能解释军械事件的事实 |
| 分段提高难度 | 工具教学、身份比对、次序推理、账目核验、视角变化、综合推断 |

战时军务是本作的谜题语言：番号、点验单、封签、押运记录、官印。具体机制为关卡设定；实物形制和术语在正式美术制作前继续考证。所有解题规则在游戏内提供，无需玩家预先了解明代军制或古代文字。

## 3. 第一章的故事闭环

开场问题：为什么我已经被列入阵亡军籍？原本由我们押运的军械去了哪里？

玩家逐步发现：

1. 陆昭的姓名和腰牌编号都被登记在阵亡条目中。
2. 同一批「甲三」号军械箱，在正式押运出发前一天就已被写成收讫。
3. 一张封签上另覆了新纸，将旧去向「西渡」盖成「东营」。
4. 被覆盖的旧封签带有副将赵廷岳的官印，与拘押令的印迹对应。

本章只建立「有人预先造账、修改去向，且副将官印牵涉其中」这一判断。官印出现不能单独证明副将本人已通敌。后续章节再调查西渡、降清部队与子时东门的计划。

章节结尾对白：
陆昭：“初九才出营，初八就已收讫……他们早把这笔账写好了。”
陆昭：“西渡。我要去那里找人。”
老军匠：“先收好这些。今夜东门的军令，正是赵副将签的。”

留钩子，仍保留后续搜证空间。

## 6. 逐题设计

### P01｜军籍中的陆昭

目的：用一次简单的道具操作教会玩家背包和近景，再给出第一个故事悬念。

可见信息：
- 桌上有带干涸泥污的腰牌，点击可拾取。主角说明这是自己的腰牌。
- 水盆与干布条均清楚可见。
- 军籍可以翻阅，按「甲字哨」等文字索引定位。
- 腰牌清理前，编号和姓名尚不能辨清。

操作：
1. 拾取干布条。
2. 选中布条，再点水盆，得到湿布。
3. 选中湿布，点击腰牌近景的污迹。动画清理，不要求精确反复擦某个像素。
4. 腰牌显示「甲字哨·十七·陆昭」。
5. 在军籍中查看甲字哨对应条目，点击「陆昭／十七／殁」进行核对。

解题结果：
- 将腰牌和军籍对应条目作为证据记入线索册。
- 主角：“番号没错，名字也没错。他们把我也算进去了。”
- 湿布保留。清理后的腰牌始终可以再次查看。

提示：
1. “腰牌上的字被污迹盖住了。”
2. “桌上的水和布条可以一起用。”
3. “先把布条蘸水，再清理腰牌；核对军籍的甲字哨第十七条。”

错误反馈示例：
- 直接把水盆用于腰牌：“端着整盆水不便，蘸湿布条更合适。”
- 乱选军籍条目：“先把姓名和番号都核对清楚。”

### P02｜百户的军匠匣

目的：提供第一道可推导、有唯一答案的机关题，奖励新区域。

设定：
这是一只百户委托老军匠制作的私用木匣，使用四枚军械图案木牌控制暗扣。它是本作的虚构机关，不作为明军制式装备介绍。

界面：
- 四个横向插位，顺序固定为左至右，并有清楚的起止标记。
- 四枚木牌可按点选或拖放排列：长戈、火铳、弓弩、盾。
- 图案下附中文名称，避免玩家不认识器物形状。
- 匣旁便笺说明：“依此次点验次序排牌。”

两处线索均在偏房，保证单场景原型能够独立完成：
A. 墙边点验便笺：“长戈先验，盾牌收尾。”
B. 床脚布包中的随行记事：“火铳验毕，再点弓弩。”全文说明是本次同一趟点验，排除跨批次歧义。

正确答案：
长戈 → 火铳 → 弓弩 → 盾。

唯一性：
戈固定第一、盾固定第四，中间仅剩铳与弓；铳先于弓，因此只有一个排列。

奖励：
- 军械库钥匙。
- 押运单：六月初九启运；箱号甲三；送往东营；随队点验顺序与上述便笺一致。
- 匣中残军令作为主线叙事物，现阶段只显示既定片段“子时……东门……不可开”。本章不另做难以辨识的猜字题。

提示：
1. “木匣的顺序和这一次点验有关。”
2. “便笺给出了首尾，随行记事给出了中间两项的先后。”
3. “从左到右：长戈、火铳、弓弩、盾。”

规则：
- 允许玩家直接输入正确排列，不要求后台先标记所有线索已读。
- 错误不扣生命、不清空已找到物品。
- 解开后保持开启，不要求重复操作。

### P03｜提前一天的收讫

目的：让文书成为操作对象，以具体矛盾推进剧情。

前提：取得押运单并进入军械库。

账册内容：
- 甲一：六月初七，东营接收。
- 乙二：六月初八，东营接收。
- 甲三：六月初八，记为本批收讫。
- 乙三：六月初十，西仓接收。

这些是虚构剧情数据，正式 UI 须给出统一月份和本批来源，避免混淆为其他年月或另一只重号货箱。甲三条目有与押运单一致的批次记号、箱号和货物名。

操作：
- 选中押运单，点击账册进行并列比对。
- 玩家按批次记号与箱号定位甲三条目，再选择需要比对的两项日期。

答案：
启运日初九；收讫日初八。账目所记的收讫早于启运。

反馈与奖励：
- 主角指出“这条账至少有问题”，不凭单一错账立即宣布通敌。
- 线索册记录一组可再次并列查看的原始文书。
- 检查甲三号箱还会看到重新贴过纸签的边角，提示检查旧封签。
- 箱边磨损、空兵器架作辅助叙事，不单独构成无需解释的密码。

提示：
1. “先确认是不是同一批甲三号箱。”
2. “看启运和收讫的日期。”
3. “同一批军械初九才启运，账册却记成初八已收讫。”

### P04｜碎裂的封签

目的：提供视觉操作，并给下一题留下看得见的异常。

来源：
老军匠从同袍遗物中收存了一包残纸，放在废祠的遗物布包中；布包附简短来源说明。玩家不需要另解一道锁才能拿到纸片。

操作：
- 四块碎封签进入独立近景。
- 按纸边撕口、编号框线及红色残印拼合。
- 支持点选后旋转，正确邻接后轻微吸附。
- 撕口、框线、残印共同提供判断依据；不以颜色作为唯一信息。

拼合后正面读到：
甲三；东营。
同时能看到：
- 一角贴着第二层薄纸；
- 部分红色印迹在正反两面呈现异常重叠；
- 靠近光源时薄纸能透光。

结果：
获得“拼好的封签”。自动保留完整近景，发现它与军械库甲三箱的重贴痕迹相关。提示玩家改变观察条件，但不自动展示下一题答案。

提示：
1. “先找能接上的外边缘。”
2. “编号框线和红印也能帮助判断位置。”
3. 显示四块纸片的目标位置轮廓，玩家仍可完成最后的归位。

### P05｜烛下旧印

目的：借鉴“使用物品改变可见信息”的解谜组织方式，形成首章的记忆点。

前提：P04 拼好的封签。偏房已有烛台，光源始终可用。

操作：
1. 选中封签，点击烛台旁的检查位置。交互定义为隔着安全距离透光查看。
2. 将纸片正反翻转并移动到透光区域。若使用触屏，用明确的翻面按钮。
3. 透光后看见新贴纸之下的旧去向“西渡”，以及此前被覆盖的旧官印。
4. 打开线索册中已看过的拘押令，进行并列印迹比较。
5. 通过相同的边框缺角和内部特征识别两处印迹关联；文字标签同时说明该印对应副将赵廷岳。

设定解释：
旧封签被覆纸改成新的目的地。本题的可见效果应通过设计好的两层纸纹理和明暗变化实现。纸张透光效果要在样板近景中先验证；如果读不清，调整纸层、文字位置与对比，而不是让玩家猜画出来的字。

答案：
- 表面目的地东营，覆盖的旧去向西渡。
- 旧封签与拘押令上的官印相符。
- 推断为副将官印牵涉军械改签，尚不能证明副将本人所做的一切。

提示：
1. “封签似乎贴了两层纸。”
2. “薄纸可以对着光检查，偏房有烛台。”
3. “透光查看旧去向，再将旧印与拘押令上的印迹比较。”

重要规则：
- 不设置烧毁封签的分支。把纸放到错误位置只反馈“靠近光看，别贴上火”。
- 识别印迹不依赖篆字知识。
- 信息出现后可留存普通清晰文本和近景，不能因动画过去而错失。
- 关键操作提供短暂、克制的光影演出，不用惊吓遮住线索。

### P06｜三条证据

目的：让玩家主动形成本章判断，连接下一章。

交互：
线索册出现三个明确问题。把已有证据放到相应位置，或点选匹配；不要求输入自由文本。

1. “时间哪里不对？”
   - 正确证据组：同批押运单初九启运 + 甲三收讫账初八。
   - 对应判断：收讫记录被提前写入，需追查。
2. “军械曾指向哪里？”
   - 正确证据：封签透光后的西渡旧字。
   - 对应判断：原先记录的去向遭覆盖。
3. “谁的官印出现在其中？”
   - 正确证据组：旧封签印迹 + 副将拘押令。
   - 对应判断：赵廷岳的官印与军械转运有关。

错误反馈具体说明缺失的联系。例如，只放拘押令时提示“还缺少军械一侧的同印证据”。

完成：
- 三组证据并列展示，触发章节结尾对白。
- 目标更新为调查西渡和子时东门军令。
- 不把本章当成法庭定罪；后续仍需查清签发与使用官印的人。

提示：
1. “先把时间、去向、官印三件事分开。”
2. “时间与官印都需要两份材料相互对应。”
3. 给出每一组材料名称，但仍展示它们如何形成判断。

## 7. 先后关系与自由探索

- P01 可独立完成，是推荐的新手引导。
- P02 可独立完成，产出进入军械库及完成 P03 所需的两件物品。
- P03 依赖 P02。
- P04 在废祠可提前完成，不强制等到查账之后。
- P05 依赖 P04；拘押令起始可读。
- P06 依赖 P03 与 P05 提供的证据；身份悬念在收尾对白中回顾。
- 已获得关键文书可无限回看，谜题答案允许提前输入。
- 剧情演出不重置已完成机关，也不关掉仍需要访问的场景。

这样既有跨场景关联，也给玩家两条可并行探索的支线：偏房木匣与废祠封签。

## 8. 通用交互规范

### 场景与近景
- 全景点物件进入近景，近景有始终可用的返回按钮。
- 出口、背包、线索册、提示入口的位置保持一致。
- 大场景点击容错范围比画面上小物件略大，近景负责精细操作。
- 首版以桌面鼠标为主，核心动作同时可由触屏点选完成。

### 背包
- 支持点选物品，再点击目标。
- 可查看物品名称和一句用途描述。
- 选中状态明显，有取消选择入口。
- 物品合成只发生在有定义的正确组合上；其他组合不损失物品。
- 关键证据不作为一次性消耗品。

### 线索册
- 原始近景、清晰文字转录和必要的并列比对同时保留。
- 记录已发现的事实，暂不替玩家自动完成所有推断。
- 点击线索可回看其来源场景，避免记忆负担。
- 军籍中的身份疑点和军械证据分栏，避免混成一条直接定罪结论。

### 提示
- 同一谜题三档：指出方向、解释关联、给出明确操作。
- 玩家主动打开，不自动打断。
- 第三档可以明确给出答案，便于完整体验故事。
- 首版不设置广告、扣分或付费提示。

### 存档与恢复
- 物品取得、机关解开、重要证据发现和转场后保存进度。
- 刷新后恢复已解机关和纸片状态。
- 单个谜题可重置自己的摆放，不能误清全部进度。
- 不用真实倒计时制造首章失败重开。

## 9. 正式美术与音效清单

### 三处场景
保留已认可的偏房、军械库与废祠风格，重新明确可交互层及留白。需要的动画集中在烛焰、布帘、少量灰尘与机关反馈。

### 关键独立资产
- 污腰牌、净腰牌、军籍近景与甲字哨条目；
- 干布、湿布、水盆；
- 军匠匣、四枚符号木牌、开启状态；
- 两份点验文字线索、押运单、军械库钥匙；
- 账册四条示例记录与甲三箱；
- 遗物布包、四块碎封签、拼合正面；
- 封签叠纸正反与透光状态；
- 拘押令、两处匹配官印近景；
- 背包、线索册、证据比对面板与提示面板。

文字不直接依赖图像生成：姓名、日期、编号、去向、规则、印迹说明都需要清楚可读并能修改。由设计控制官印特征，不让生成图中的随机字形成为谜底。

### 声音
- 夜风、远处巡更或营中脚步；
- 纸张、木匣、钥匙与金属物件的轻反馈；
- 发现自己名字时环境声短暂减弱；
- 证据完成后以远处更声和灯光变化衔接剧情。
关键声响附简短文本或视觉反馈，不要求听觉辨音才能解题。

## 11. 验证与验收

设计检查：
- P02 四种图案的排列在全部约束下只有一个正确解。
- 文书批次、姓名、编号、日期、去向前后一致。
- 同印只能支持关联判断，不能替代后续通敌证据。
- 首章不包含必须靠外部历史常识才能想到的答案。

流程检查：
- 先查废祠或先解木匣均能继续。
- 提前输入正确暗匣答案能正常获得奖励。
- 正确使用物品一次即可，不因误点消耗关键物。
- 近景关闭、转场及刷新后进度可恢复。
- 封签不会烧毁，拼图可恢复，不存在永久丢证据的状态。
- 每道谜题的三级提示均对应该题当前状态。

盲测记录：
- 玩家首次理解目标的位置；
- 每次卡住时看到过哪些线索；
- 是否因为物件太暗、文字太小或点击区不明确而卡住；
- 是否能用自己的话解释暗匣答案和账目矛盾；
- 揭示官印后是否想继续调查西渡。
