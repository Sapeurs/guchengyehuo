# 第22版：行动因果与救援顺序

本版网页与Android共用同一份游戏构建内容，Android版本0.22.0 / 2200。

- 第二关木门移除底票前置。门板、门销和推门自身仍有物理顺序。
- 第三关取得架后留底即可比较相反命令；无需先解废祠口信或转好号灯。只有补报动作需要号灯恢复朝向；界面保留比对结果并解释缺什么，状态层也防止绕过。
- 第四关包扎、打开出口后即可护送，不再要求签押。护送时收好可能漏拿的半页纸。救出后的第三场景变为旧道外避风处，再听亲见并签押，章节仍需完成亲见。半页纸不再能卡住救人。
- 受伤、包扎后、救出后分别使用对应全景。首次见面改为“把门带上”，与已燃油灯一致。新增救出瞬间，支持中断和刷新续接。
- 第五关新增老军担保下的有限协助；新访问需要完成盘问，旧版已有调查进度保持通行。担保状态随本关重玩清除、恢复备份时恢复，其他章节重玩保留。之后由老军指挥守案并派人陪同上楼，不把陆昭写成可以直接接管守军的人。
- 减少报告口吻。保留具体证据与不确定性，用守军怕开错门、伤者怕追兵、守备认回生还者等反应表达。

## 验证

- 85项自动检查通过，含六关可达性、救人先于签押、漏拿半页纸、旧版先签押存档、分阶段补报及担保重玩隔离。
- TypeScript和生产构建通过。新增文本重新生成三个授权字体子集。
- 桌面浏览器实际验证：未拿底票开木门；未解口信/号灯先比对命令，补报得到具体反馈；漏拿半页纸救人后刷新并继续，在避风处只询问必要话题即可签押完成第四关；第五关盘问及担保刷新保存。
- Android release及lint通过后，核对包名、版本、签名、零权限和离线文件逐字节一致性。仍缺真实Android设备安装、触摸及全流程测试；没有进行不知答案玩家的盲测。
