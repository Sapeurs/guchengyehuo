| 行动 | 可见结果 | 后续用途 |
| --- | --- | --- |
| 用撬棍抬外层横木 | 横木抬起，露出回弹舌 | 砝码才能放入 |
| 放铜砝码、推木闩 | 主闩退出，回到开箱后的前院 | 可掀内衬 |
| 掀箱衬、取残签 | 衬布移到一旁，残签分别拾取；不重复生成 | 到侧库拼签 |

| 将底单放到收讫簿旁核对 | 在实际文书上点日期，自动记下矛盾 | 脚步与窗外灯影进入簿房 |
| 主动罩住灯焰 | 巡兵离去，场景保持遮灯后的光照与灯罩原画 | 恢复自由调查 |
| 拼合六片残签 | 沿框线、残印、字行接合；回到桌上留有整签的侧库 | 看见双层纸边 |
| 放灯、翻纸、拖纸 | 旧墨随接近灯光连续变清晰；不是数字组合 | 清晰范围内点“细看旧墨” |
| 对照残印 | 旋转与叠合后标记两种相同损伤，自动结束 | 只确认同印模，不直接定罪 |
| 提灯扫过车辙 | 灯光揭露湿泥转弯擦痕、夹带芦苇 | 取代原末尾的文字证据配对题 |
