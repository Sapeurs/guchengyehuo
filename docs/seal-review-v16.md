# 查清后仍可翻看印迹 · v16

用户反馈“甲乙丙是什么意思，为什么乙之后丙点不出来”。原界面用甲乙丙编号三处旧印，且在验印完成后禁用了所有翻看按钮，没有说明完成与禁用原因。

- 翻看按钮改为“第1处、第2处、第3处”，增加“翻看印迹”说明，纸面标题同步显示当前印迹编号。
- 未查清时说明旧签上有三处印迹，可逐一翻看与拘令对照。求助文字同步使用编号。
- 查清后仍可切换三处印迹、开启或关闭对照；显示“验印已查清，三处旧印仍可逐一翻看”。
- 查看其他印迹属于临时浏览，不写入解谜草稿和已解记录；退后再进入，仍先展示已确认的第2处物证。
- 查清后每处都有准确说明：第1处外框不合，第2处已确认同印，第3处印文裂痕不同。不会因切换而错误声称其他印迹也已吻合。

验证：36/36 项测试及生产构建通过；新增已解浏览状态测试，确保第2→第3→第1→第2处切换与对照开关不修改已确认物证。桌面浏览器实测同一路径及退后重入，“两处残印”仍为已查清，关卡进度仍为4/6。截图：screenshots/seal-review-v16.jpg。
