# 第21版：发现、近景与停顿

## 这轮要改善的体验

把可操作性继续推进到能看懂因果、愿意继续调查；保留既有六关与存档。

- 西渡关灯成为可恢复的小实验：先看一柄两灯；误拆主索会导致两灯都灭，拆掉两根也不算完成；接回主索并去掉横接旁索后，验货亮、放行暗，才得到发现。它与提前留放行印的底票相互解释。
- 绳梯近景换为同场景的船舷与码头，梯子使用透明木材质构件，放梯有实际位姿变化。试玩发现且修复铁钩触点被木梯触点遮挡的问题。
- 包扎换为同袍真实衣袖、手臂、布层的三个状态。覆净布后，一次拖动即可收住布尾；点按和键盘保留等效入口，取消或反向拖动不算完成。
- 陈九成辨认取信人后即可签押；倒灯与留底见闻为可继续追问的内容，签押后也能补问。签押原件只呈现已经听过的可选见闻。
- 封船、封案、交接缩短为合适的收尾行动，不重复要求多次同类确认。随身已有工具可从近景一键取用，仍需明确使用，避免把拥有道具当作已经应用。
- 找到同袍、照料后重逢、关灯发现、城台回灯和更正名册有独立短场面。继续始终可用，不设强制等待；减少动态效果时直接显示最终状态。
- 新发现先落盘再演出；中断后继续会恢复未看完的场面。旧已完成存档不补播所有旧事件，切章及重玩不带入别章场面。
- 城台近景把灯光真正送向远处的窗口；两台回应有先后变化。河边、暗室与城楼的环境混音和短音乐动机分开。
- 场景与篇章页减少“6/6待办”的数字呈现，保留手记、主动求助与可达场景提示。

新增素材使用本作已有场景/角色作为参考，由内置图像生成工具生成；不使用其他商业游戏的素材。

| 素材 | 使用与提示词要点 |

| `c2-dock-close-v21.png` | 原西渡船坞的近景；保留主缆、船身、月夜与木桩；船边留出可动木梯位置，不预画梯子。 |
| `c4-bandage-states-v21.png` | 同一陈九成、衣袖、机位与灯光的三等宽状态图：旧布松开、净布覆上、布尾收妥；无裸露伤口。CSS按状态显示，不二次改绘。 |
| `c6-towers-v21.png` | 明代城台夜景，近处机械号灯、远处两座黑窗；不预画回灯和光束，实际回应由交互状态控制。 |

字幕和原件新增汉字重新生成本地字库子集，延续 Ma Shan Zheng / LXGW WenKai / Noto Sans CJK 分工与已有授权。脚本为 `scripts/subset-field-fonts.py`；完整上游字体仅保留在忽略目录中。

## 已验证与边界

- 82项状态与存档测试，覆盖新关灯的错误/恢复分支、旧关灯草稿迁移、可选见闻、简化操作、发现中断恢复。
- 桌面预览实际操作绳梯、误拆和接回主索、正常关灯发现、途中刷新、同袍现身、一次鼠标拖动包扎、只问取信人便签押、签后追问、城台错序/正确回灯，以及封案至最终生还见证。
- 第一关和第三、五关的既有状态逻辑继续由现有测试覆盖；本轮没有声称重新人工完整通关全部六关。
- 没有未知解玩家盲测、真实手机触屏验收或人物配音。部分其他机关仍使用可动SVG构件，尚未达到全部近景统一精修。
- Android沿用离线WebView外壳和原签名。构建、资源一致性与签名校验独立记录；不把APK可构建当作真机可玩验收。
