## 仍需逐关改造

这些不是本次贴图修正已经解决的问题：

- 第二至六关的 30 个谜题仍共用排序、配对、转盘等面板，实物操作表现不足。
- 连杆谜题仍是四个独立转角，缺少贯通机构、输入输出和动作结果。
- 多数机关解开后，主场景没有对应的开门、停轮、换灯等持续变化。
- 部分实物线索仍靠旁侧抄记说明，尚未具备逐字可读的专用物件近景。
- 第一关以外缺少人物反应与事件变化，场景仍显静止。

## 验证

- npm test：31/31 通过；覆盖六关可解性、道具使用、保存恢复、序章流程与第一关互动。
- npm run build：TypeScript 检查和 Vite 构建通过。
- 浏览器实际验证：第一关闭箱→取撬棍→用在箱上→近景变为撬开状态；重玩前记录可恢复。
- 浏览器实际验证：序章已解匣存档进入房间可见打开的箱子，点击打开位置可继续检视。
- 浏览器查看：废祠原处调查、普通道具等比裁切、东门摆放、破晓案上毛笔、马厩拾取物、船舱油灯与麻绳。
- 浏览器扩展自身报 metadata 错误，未观察到对应游戏脚本错误；未据此声称全部设备均已验收。
- 本轮未模拟手机屏幕，不列移动端实测结论。
