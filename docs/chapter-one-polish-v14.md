# 第一关整体精修 · v14

本轮把 v13 的开箱近景标准延伸到对账、拼签、透光、验印、查车辙和离场。序章及后五关内容不扩写。

## 实际变化

- 簿房与侧库各有一张与原房间对应的完整桌面近景，文书、纸片、灯与印迹落在同一幅场景中。取消这一关旧的模糊背景、居中机关卡片和常驻工具列表。
- 对账只在原件上圈日期。未取得底单时只抄录眼前的交割簿，修复之前自动读入未取得底单的问题。
- 残签支持拖动交换与点按两片交换；沿连续边框和朱印接合。拼好后收拢为同一张纸，右下角留出双层纸边。
- 封签翻背后，正面墨迹反透；移动到灯焰左上方才逐渐显出旧去向。没有数字档位或单独的答案列表。
- 验印使用真实印迹图形；可翻看三处残印，转动纸角，拖动留印叠合，在印痕本身圈两处损伤。保留按钮和键盘可达的等效操作。
- 车辙近景铺满画面，拖动提灯照出泥纹与芦苇；查清后还可移动灯光与回看痕迹。
- 除对账后必须退回房间应对巡兵外，解开物件后保留物件和短对白，不自动退出近景，也不立即展示一大段结论。
- 主场景保留开箱、抽屉、遮灯、封签、油灯和验印原件的变化。军匠新增对提前收讫与河滩芦苇的回应。
- 六项调查完成后，前院门打开，军匠让开通道。玩家从门离开，经离场对话进入第二关。

## 存档边界

- 存档键与格式版本保持不变；旧版已解记录保留。
- 旧记录若缺少当前物件草稿，查看时重建已解物证的展示状态，不改写原存档和未完成摆放。
- “重访军器库”先备份第一关，篇章页可恢复。其他章节的物品、调查、文书与开场记录保留。

## 验证与实测

- TypeScript / Vite 生产构建通过；34/34 项测试通过。新增旧版已解记录的物证展示测试，覆盖不改写原记录和未完成草稿。
- 桌面浏览器全程手动操作：空手看账、检查手记没有提前获得底单；取砝码、拉抽屉取灯；收撬棍与底单；压撬、压舌、抽木、开盖、掀布、取签。
- 同桌对账触发巡兵；遮灯后可以继续进入侧库。
- 实测拖动纸片交换后刷新，继续仍保留交换位置；点按其余纸片完成拼合。
- 翻背、拖动封签到灯旁、细看旧墨；选择乙印、转两次、拖动叠合、直接圈两处断口完成验印。
