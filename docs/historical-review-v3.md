# 偏房文书与时代氛围检查

日期：2026-11-11

范围为当前已实现的序章：开始菜单、开场、军营偏房、腰牌、水盆、行伍册、两份点验记、札付、军匠木匣、解运底单、残札、手记、提示、离开过场。未将尚未开发的军器库与废祠标为已经检查完成。

## 判断与修订

古代也有按格式填记的册簿。旧版的问题是把文物做成现代横向数据表：表头、等高人员行、统一状态列和选中高亮。仅加旧纸纹理不足以解决这个问题。

| 检查位置 | 本轮处理 |
| --- | --- |
| 所谓“伤亡归营册” | 改称东营行伍册；不再把每日到单、军籍户籍与战后附注当作同一种公文 |
| 人员记录 | 右起竖写逐名条记；将初九日阵亡、未回等写成边旁附记；删除横表、表头、选中行色块与自动圈选 |
| 册页材质 | 重做纸捻装订的展开册页底图；文字用真实字形叠加，不让图像生成器伪造可读史料 |
| 场景案上册子 | 原画内页也改为竖界栏和竖写墨迹，保持原有物件坐标与点击位置 |
| 点验便笺、随行记事 | 改为右起竖写短记，去掉网页标题分隔线和现代卡片式内容 |
| 押运单 | 删除二乘二“启运／箱号／送往／点验”字段卡，改为解运底单的连续竖行 |
| 拘押文书 | 以札付形式作原创改写，去掉“核身份”式现代办事措辞和装饰性假官印；落款保留副将姓名 |
| 百户残令 | 文物画面作为染血残札；游戏说明仍用易懂的“残缺军令”，不冒充诏敕 |
| 武器 | 原长戈改为长枪；尖底盾图样改为圆藤牌；木牌题字、便笺、提示和手记同步。旧存档中的内部武器 ID 保留 |
| 腰牌 | 按《纪效新书》所述木腰牌取材，改为木质；不宣称轮廓、绳色和尺寸属于明军全国统一形制 |
| 机关匣 | 明确是老军匠替百户私制的原创机关，不冒称明军制式锁具 |
| 时间 | 初九日遇袭、十一日夜归营，开场“三日前”改为“两日前” |
| 字体与阅读 | 可读内容简体优先：册页姓名、附记、文书正文、腰牌与机关文字均用简体；仅“行伍冊”装饰题签保留繁体。册页用支持简体的本地毛笔字，文书用文楷，保留“放大细看”控制 |
| 场景道具与提示 | 继续复用实物原画，不恢复自动悬停标签、方框或答案提示；生活器物与建筑按当前插画作风格检查 |

## 一手资料及使用边界

- 《纪效新书》卷一：行伍册、腰牌纸式、营伍／年貌／贯址登记，及长枪、藤牌、火铳与弓弩等器械。
  https://www.shidianguji.com/book/SK1397/chapter/1la03mtmbcw1r
- 《纪效新书》卷五：每日填到单，已到报总数，未到及有差开花名；逃故另报手本。
  https://www.shidianguji.com/book/SK1397/chapter/1la03mzhycch0
- 《纪效新书》卷首《正行伍说》：木腰牌及开写姓名、牌阴印紧要军法。这是戚继光方案的依据，不足以断言明代绝无铁腰牌。
  https://www.shidianguji.com/zh/book/SK1397/chapter/1la03mr4f9xcj
- 《大明会典》卷一百九十二军器条：军器制造、起解、辨验与库房交收，可据以改写解运语句。
  https://www.shidianguji.com/book/7543591175140147227/chapter/1lbxfssfdsqwb
- 中国第一历史档案馆《中国明代档案总汇》简介：明档包含札付、手札、塘报、册簿等多种文书。本轮只参考文种，不把游戏中的公文说成馆藏原件摹本。
  https://fhac.com.cn/research/research_publishing/detail/1936.html

没有找到与本作年代、营伍、用途完全相同的“伤亡归营册”原件，故本版是据资料作艺术化设计，不是特定军册的复原。虚构城池、人物、甲字哨命名、私制机关、精简的人员条记与交互判定属于原创。书写字体为现代数字楷体，版式为阅读与操作作了取舍。百户称谓不被用来建立一套全国统一的“百户—哨—队”编制图。

## 资产与字体

- `public/assets/crafted/muster-folio-v3.png`：内置图像生成制作的无字双页底图，1586×992，原样保存；内容文字由 `src/muster.ts` 生成。
- `public/assets/room-v3.png`：仅以旧场景作参考修改案上册子，1672×941。生成编辑不是逐像素无损，热点对齐另在浏览器检查。
- 字体源：Google Fonts 的 LXGW WenKai TC Regular、Noto Sans SC 与 Ma Shan Zheng；项目保留许可和重命名子集。
  https://github.com/google/fonts/tree/main/ofl/lxgwwenkaitc

书册底图提示：明末军营旧册，近正上方，朴素纸捻装订，两页暖灰麻／竹纸，淡竖界栏，无横向表格、文字、伪字、印章或道具；正文安全区为左 x9–46%、右 x54–91%，两页 y14–83%。暖烛光与极弱月光，朴素哑光材质。

场景编辑提示：只替换案上册子内页的横表与墨迹为传统竖界栏、右起竖写墨迹；保持书页轮廓、透视、尺寸和原有房间全部物件的位置。

腰牌成对资产为 `token-wood-clean-v3.png`、`token-wood-dirty-v3.png`：内置图像生成将原铁面改为无金属包边的哑光暗褐实木，维持轮廓、绳结、挂孔和无字牌面；脏版只加自然干泥。透明画布尺寸不完全相同，擦拭层按等比例居中绘制，避免拉伸物件。

文书纸面另外使用 `paper-leaf-blank-v3.png`、`torn-letter-blank-v3.png` 的真实透明纹理；后者与背包残札共用原画。内置生成提示要求朴素竹麻纸、自然纤维毛边、轻微折痕、无字无印；残札从原残页去除伪字并保留血渍。浏览器排字避开左侧血污，不再用几何锯齿模拟撕口。文物字迹标注 `translate="no"`，避免浏览器翻译改动线索。
