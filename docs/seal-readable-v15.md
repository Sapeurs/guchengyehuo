# 验印可读性修正 · v15

玩家反馈旧的转动叠合机关像“鬼画符”，不知道在做什么。根因是印章由无语义的几何线条组成，随机朝向、叠合和圈记又同时出现，缺少任务目的。

## 改动

- 印文改成可读的简体“军器验讫”四字。沿用原场景与纸张；印迹用项目本地字体及 SVG 磨损遮罩绘制，没有新增生成图片。
- 明确两份文书分别是“拘令上的印”和“旧封签上的印”。任务是核对同位置的外框缺口和印文裂痕，而非认字或猜密码。
- 三处旧印均摆正，取消玩家转动步骤。对照可直接点按钮，也可把左纸拖向右纸；灰线与朱红墨有文字图例。
- 在旧印上直接圈记。未对照时说明操作顺序；甲处外框不合、丙处印文裂痕不合、乙处只找到一处、圈错位置都有对应反馈。再次点已圈处可擦去。
- 求助文案同步修改，不再要求旋转两次或识别抽象弯钩。
- 保留存档格式、已解标记与旧的内部方向字段。玩家再次操作时仅将当前旧印摆正，保留其选片、圈记与对照状态；不会把错误印迹直接判成正确。

## 验证

- 35/35 项测试通过，包含新增的旧方向归正、圈记保留、错误印迹不得通过测试。
- TypeScript / Vite 生产构建通过。
- 桌面浏览器正常推进开箱、取签、拼合与透光后进入验印。
- 实测未对照先圈、甲印对照错误、丙印仅外框相似、乙印拖动对照、只圈一处、圈错再擦去、两处匹配完成；整个过程没有转动操作。
- 一处圈记后刷新，旧印选择、对照与圈记保留；完成后回看正常。

- 未新增手机实体设备或历史印章专业考证；四字印文是为游戏可读性设计的表现。
